Topic Catalog

AI Coding — Core Topics

The shortlist of core topics for the SDLC / AI-coding curriculum — names and one-line hooks.

The Shortlist

1

Spec-Driven Development (SDD) & OpenSpec

Writing specs as the primary artifact and letting agents implement them; OpenSpec / spec-kit style workflows, and when a spec beats a prompt.

2

Cursor Auto vs Max Mode

Model-selection strategy: when auto routing is good enough, when to pay for max-mode long context, and the cost/quality trade-offs.

3

Subagents

Delegating scoped work to child agents — explore/plan/review specialists, context isolation, and when fan-out helps vs hurts.

4

CLI vs MCP

Two ways to give agents capabilities: shelling out to CLIs vs structured MCP servers — token cost, discoverability, auth, and composability.

5

Cursor Hooks

Deterministic guardrails around agent actions — pre/post tool-call hooks for formatting, policy enforcement, secrets blocking, and audit.

6

Git Worktrees

Running multiple agents in parallel on isolated checkouts of the same repo — worktree workflows, merge strategy, and cleanup hygiene.

7

Permissions & Sandboxing

What makes "YOLO mode" safe: OS-level sandboxes (Cursor's Seatbelt/Landlock terminal sandbox, deny-by-default network, workspace-scoped writes), allowlists vs approval prompts, and escalation paths.

8

Background & Parallel Agents

Fire-and-forget agents: queues of tasks, babysitting many sessions at once, and the new bottleneck — human attention, not typing speed.
