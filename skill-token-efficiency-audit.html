The two failure patterns iTwo ways progressive disclosure can fail. Max scenarios: the skill fires and loads every doc — no partitioning, pure overhead. Zero scenarios: the skill fires but loads no reference docs at all (only the mandatory SKILL.md) — it triggered for nothing and still charged you SKILL.md's tokens. Both are bad; you want most fires in the middle.
