Baseline requirements for a passing skill run — things that must hold regardless of test quality or depth.

1
The full test flow reaches the end without blocking errors

A skill run must complete the end-to-end workflow without crashing, hanging, or raising an unhandled error at any step — even if the tests it produces are minimal or trivial. The Double Gate entry and exit must both be reachable. A run that stalls on a missing config key, a hardcoded path that doesn't exist, or an agent that stops mid-workflow without a clear handoff is considered a failure regardless of what was produced.

2
An artifacts folder is created containing a plan, test results, and a transcript

Every run must produce a working folder containing at minimum three artifacts: a test-plan.md (the entry gate output), a test-results.md (the exit gate output), and a transcript.jsonl (the structured event log). Runs that complete without all three files present in the session folder do not meet this requirement, even if the tests themselves pass.
