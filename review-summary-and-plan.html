#04test_repeat_flag uses a shell loop instead of Vitest's --repeatC2

The current value spins a for i in $(seq ...) shell loop — bash-only, no clean failure aggregation. Vitest's native --repeat <n> flag runs the test N times within a single process with proper per-iteration reporting. Replace with: pnpm test:component run {file} -t "{title}" --repeat {n} --reporter=verbose.
